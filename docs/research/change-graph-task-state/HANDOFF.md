## 每次结束工作必须留下什么

首次实际执行 G1 时创建 `research-execution-ledger.md`，以后只追加阶段尝试；本文只维护最新检查点，并链接到对应记录。不创建空结果文档。每条尝试记录输入版本、交付位置、实际检查及证据、未决问题、通过/返工/受阻判定和明确下一步。原始资料路径与来源见清单，不能把唯一结果只放在聊天里。

遇到缺失本地原文，先查来源清单的固定官方地址；获取新的副本时保存新批次并核对版本。无法取回则记录受阻或用别的合格材料继续，不能补写“应当发生”的过程。无网络时只能处理已有材料，不能声称完成广搜。

## 交接自检

接手者应仅凭上述文档回答：目标是什么；哪个版本当前有效；哪些内容只是候选；现在做到哪一关；第一项具体动作是什么；资料在哪里；这一关交什么；怎样判定通过；失败后回到哪里；哪些动作需要另行批准。
